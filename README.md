## 🚀 Quick Start

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools or dependencies required

### Installation

1. Clone the repository:
```bash
git clone https://github.com/atilioobadia-cpu/atilio-portfolio.git
cd atilio-portfolio
```

2. Open the portfolio:
```bash
# Simply open the index.html file in your browser
# Or use a local server:
python -m http.server 8000
# Then visit: http://localhost:8000
```

3. View in browser:
- Open `index.html` directly in your browser
- Or serve via HTTP for best experience

## 💻 Customization

### Editing Content

1. **Personal Information** - Update in HTML:
```html
<h1 class="hero-name">Your Name</h1>
<p class="hero-role">Your role description</p>
```

2. **Services** - Modify the services grid section
3. **Projects** - Update project table with your work
4. **Skills** - Add/remove skills and adjust proficiency bars

### Theme Colors

CSS variables are defined at the top of the stylesheet:
```css
:root {
  --primary: #171717;
  --text: #1a1f2e;
  --accent: #374151;
  /* ... more variables ... */
}
```
